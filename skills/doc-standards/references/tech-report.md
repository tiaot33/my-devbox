# 科技报告

## 适用

- 读者：
  - 本领域的专业读者：据报告重复调查研究过程、评议研究结果。
  - 资助方、主管部门、管理决策者：读结论和行动建议，决定下一步。
  - 科技报告收藏和检索机构：按辑要页著录。
- 用在：科研项目、工程项目的进展报告（年度、中期）、专题报告（调查、研究、论证、考察、观测、测试、设计、分析、实验、研制、施工、演示验证、鉴定）、最终报告（技术总结报告）。
- 不适用：
  - 投期刊的学术论文、学位论文 → `thesis.md`
  - 软件测试计划、测试报告 → `test-docs.md`
  - 软件模块、接口、数据设计说明 → `design.md`
  - 软件项目的可行性分析报告、开发总结报告 → `lifecycle-other.md`
  - 标准、技术规范 → `standard.md`
  - 面向公众的科普稿 → `popular-science.md`
  - Agent 完成任务后给用户的结果汇报 → `agent-report.md`
  - 项目申报书、科研可行性研究报告、结题验收的工作报告（讲经费和组织管理）、检验检测机构按委托出具的检验检测报告 → 本 skill 未收录，在交付说明里告诉用户只按 `base.md` 写。

## 必需章节

下文的"宜""一般"是推荐级要求：默认照做；用户或接收方另有规定时按其规定，并在交付说明里写明。

按前置部分、正文部分、结尾部分三段排列，顺序不变。三个部分和"主体"是分组名，不写成标题；主体由若干章组成，按内容命名。

**前置部分**

1. **封面**：写下列项目；标"有则写"的项目没有时，删掉该栏。
   - 密级：印刷版放右上角。
   - 报告编号：放左上角，可以有多个。
   - 题名和副题名。
   - 作者及单位。
   - 完成日期。
   - 备注（有则写）：发行限制、版权、资助、审核签名、免责声明。
   - 资助机构（有则写：与完成机构不同时）：写全称。
   - 项目（课题）编号（有则写：受资助时）。
   - ISSN、ISBN（有则写）。
   - 出版项（有则写）：出版地、出版者、出版日期。
2. **封二**（可选：要放备注或其他需注明的事项时）：发行限制、版权、审核签名等备注。
3. **题名页**（可选：7713.3 未给使用条件）：密级、报告编号、报告类型和起止日期、题名、作者及单位、完成日期、资助机构、项目编号、备注、出版项。题名页为前置部分第 I 页。
4. **辑要页**：按附录 D 的 12 栏填写：
   - 题名
   - 作者及单位
   - 报告类型与起止日期
   - 辑要页密级
   - 报告密级
   - 报告编号
   - 完成日期
   - 总页数
   - 备注
   - 摘要和关键词
   - 支持渠道：项目名称、承担单位、负责人、立项部门、项目编号、计划名称
   - 联系人
5. **序或前言**（可选：要交代缘起、背景、资助和协作经过时；也可以写进引言）：另起页，放在辑要页之后。
6. **致谢**（可选：有资助方、协作单位、提建议者或转载权利人时；也可以放进序或前言）：基金、合同单位、协助者、提建议者、转载引用的权利人。
7. **摘要页**（可选：摘要和关键词不放辑要页时）：另起页，放在目次前。
8. **目次**：列到第二或第三层级；列了某一层级，就列出该层级全部章节的编号、标题和页码。分卷报告在最后一卷列全部目次。
9. **插图和附表清单**（可选：图表合计超过 5 个时）：图清单在前，表清单在后。
10. **符号和缩略语说明**（可选：非本领域通行的符号、缩略语超过 5 个时）：汇集成表。

**正文部分**

11. **引言**（可选：英文报告必需）：背景、意义、范围、对象、目的、前人工作、理论基础、研究设想、方法、预期结果，可指明读者对象。短篇报告可以只写一段。
12. **主体**：理论、假设、方法、试验方法和过程，关键装置、仪器、材料；结果及其准确性和意义的讨论。历史回顾、文献综述、理论分析、方法、结果和讨论宜各自成章。
13. **结论**：最终的、总体的结论；得不出结论时写必要的讨论。
14. **建议**（可选：要提行动建议时；也可以并入结论）：下一步工作、未来研究、存在问题与解决办法。
15. **参考文献**（有条件：有引用时必需）：放在正文部分最后，宜另起页。

**结尾部分**

16. **附录**（有条件：有附录材料时必需）：影响正文条理但需要完整给出的材料、篇幅过大的材料、对同行有参考价值的材料、参考书目。宜另起页。
17. **索引**（可选：50 页及以上时）：主题及其页码、章节号或链接。
18. **发行列表**（可选：有发行控制时）：接收机构或个人的完整通信地址，单独成页或放在封三。
19. **封底**（可选：印刷版宜有）：ISBN、与封面相同的密级、出版者名称和地址，也可以是空白页。

## 写作规则

摘要与关键词、参考文献著录、图表公式、章节与附录编号的共用写法见 `blocks/gbt7713-7714.md`，动笔前读。下文只写科技报告特有的部分。

### 动笔前

动笔前定下面四件事，写进交付说明（不进报告正文）：

1. **报告类型和覆盖期**：进展、专题还是最终报告；报告覆盖的起止日期。三类报告共用本文件的骨架，类型和起止日期写在题名页和辑要页上。
2. **载体**：排版稿（Word、PDF、印刷版）还是 Markdown 或纯文本初稿。两者的要求差别见"交付 Markdown 或纯文本初稿时"和"排版稿"。
3. **密级与发行控制**：有无密级、是否限制发行。
4. **模板**：问用户有没有资助方或项目管理机构的模板。有模板时按模板的章节写，本文件只补模板缺的元数据，如辑要页、报告编号、密级。

### 与 base.md 不同的地方

- 结论先行由辑要页和摘要承担：引言不写结论，结论章放在主体之后。base 清单"开头一段写出了结论"改查摘要是否写了结论。
- "必需章节"里的章节名都是固定标题。主体各章用名词短语标出内容，如"试验方法""观测结果"；节标题可以写成概括结论的陈述句。
- 研究方法、过程、失败的试验和负面结果是读者重复研究要用的内容，照实写进主体；序或前言里的资助、协作经过也保留。base 的"删掉作者自己的工作经过"不适用。
- 用"本报告""本研究""运营单位"这类明确主语，不用"你"称呼读者。
- 建议写成"建议 + 执行者（已知时）+ 动作 + 条件或理由"，如"建议运营单位在通车后第 12～14 个月检测洞口内 0～100 m 段"。"建议"一词不算情态词，不改成"必须"，也不写"宜""应"。
- 摘要可以按目的、方法、结果、结论分成 2～4 段，每段仍守 base 的段长和句长。

### 交付 Markdown 或纯文本初稿时

- 页码、另起页、三线表、续图续表、封底留到排版阶段做，初稿里不模拟。审查清单里带"排版稿："的条目，以及 `blocks/gbt7713-7714.md` 清单里的三线表、续表条目，初稿标不适用，原因写"无分页"。
- 辑要页"总页数"写 `【待补：排版后统计，含封面和封底】`。
- 目次手写到第二层级，在交付说明里提醒用户排版时改成自动生成。

### 元数据与封面

- 封面、题名页、辑要页上的题名、作者、编号、日期等元数据逐字一致。
- 题名只用文字和常见缩略词，选词兼顾关键词和二次文献检索；语意未尽时加副题名。
- 题名和副题名宜中英文对照。分卷报告用副题名区分各卷，并给卷编号（阿拉伯数字）。
- 作者按贡献大小排序，其他参与者写进致谢；团体作者写全称，单位写规范名称；人名拼音按 GB/T 16159。
- 完成日期和出版日期写成 YYYY-MM-DD，正文其他日期也用这种写法，满足 base 的"同一文档只用一种"。
- 密级按 GB/T 30534 标识，报告编号按 GB/T 15416 编制。密级栏不删；用户没给时写 `【待补：报告密级】`、`【待补：报告编号】`。

### 摘要与关键词

- 中文摘要和英文摘要都写。中文一般 300～600 字，英文一般 300 个左右实词（不计冠词、介词、连词），特殊需要可以略多。
- 英文摘要和英文关键词放在中文关键词之后，内容与中文摘要逐项对应；接收方模板另有位置时按模板。
- 摘要的四项内容见 `blocks/gbt7713-7714.md`；只写报告里的事实。
- 摘要只用文字和公知公用的符号、术语。
- 关键词的数量、出处、选词和位置见 `blocks/gbt7713-7714.md`。

### 引言、主体、结论

- 引言写研究的起点和设想；发现、结论、建议留给后文，摘要里的句子不在引言重复。
- 方法、过程、装置写到本领域专业读者能据此重复研究的程度：写明仪器型号和精度、材料规格、试验条件、计量单位制。
- 讨论结果的准确性和意义。
- 正文保留支撑结论的数据，各轮原始数据放附录。
- 结论写成对全文的总体判断，不按章罗列各章小结。

### 参考文献与著录

- 著录规则见 `blocks/gbt7713-7714.md`。7713.3 引用 GB/T 7714 时没注日期，所以适用最新版。
- 报告的文献类型标识用 `[R]`。
- 2026-07-01 前已完成的稿件，按接收方要求选 2015 版或 2025 版，在交付说明里写明用的哪一版。
- 读过但没引用的文献放进附录"参考书目"。
- 参考文献表标题下写一行 `【待补：按 GB/T 7714-2025 核对著录格式】`，不在每条文献后重复；已对照 2025 版原文核对过的不写。

### 编号与附录

- 章节与附录的编号规则见 `blocks/gbt7713-7714.md`。
- 每个附录都在正文相关处提到，如"推导过程见附录 B"。
- 附录内的章、图、表、式、文献带字母前缀，如 A1、图 A1、表 B2、式(B3)、文献[A5]。
- base 的"一、""（一）"序次语只用于段内列项。
- 编号后空一个字的间隙再写标题，比 base 的"空一格"具体；Markdown 标题里用一个半角空格。

### 图、表、公式

- 图表公式的共用写法见 `blocks/gbt7713-7714.md`。
- 要画图时交给 `dataviz`，并要求：各系列用线型、标记或网纹区分，灰度打印仍能分辨。
- 图注放在图题上方；表注放在表下方。
- 公式只在需要相互参照时编号。
- 长公式在 =、+、-、×、/ 之前或括号之后换行。

### 排版稿

- 电子版目次自动生成。
- 页码：前置部分用罗马数字单独连续编排，题名页为第 I 页；正文和结尾部分用阿拉伯数字连续编排；封面、封底不编页码，但计入辑要页的总页数。
- 印刷版的正文从新一页的右页（奇数页）开始；电子版可以用链接组织章节。
- 电子版中图表与引用它的文字不在同一屏时，加内部链接。

### 注释与勘误

- 没有文献来源的补充说明写成脚注或尾注，篇幅长的报告用脚注。
- 图、表、公式内的注释用上标数字单独顺序编号，与正文注释的编号分开。
- 发布后改错时出勘误表，三栏为"页（或章节）｜原文｜更正"；印刷版插在封面之后，电子版在元数据的版本信息里记录。

### 英文报告（Z39.18）

写英文报告，或报告交给美国联邦机构时，在上文基础上补下列要求。两套规定不同时，英文报告按本节。

- 前置部分补 Notice Section（有知识产权或访问限制时）和 Report Documentation Page（SF 298；交联邦机构时必须用，学术和产业报告可选）。
- 正文补一节 Summary：问题、主要结果和结论、给决策者的建议；只写正文里有的内容，不含参考文献和交叉引用。印刷版超过 50 页时，给管理层另写非技术性的执行摘要。
- Abstract 约 200 词，写成报道性摘要（目的、范围、方法、主要发现）；不引用文献、图、表。执行摘要可以代替 Abstract，不超过 10 页。
- 题名选能区分本报告和同主题其他报告的词，不以"Report on…"开头；题名里的缩略语写全称。
- 作者只列产生内容、能在同行面前为内容辩护的人；不写学位。
- Foreword 由作者以外的权威撰写并署名，Preface 由作者撰写；两者内容不重复。
- Results and Discussion 说明结果怎么得出、准确度如何；对结果的诠释写在 Conclusions。
- 按内容选结论节名：脱离具体条件的推论用 Conclusions，只陈述本次调查的事实发现用 Restatement of Results，含作者意见用 Concluding Remarks。
- 标题不超过 5 级。
- 转引的图表加来源行：原样使用写"Source:"，改动过写"Adapted from"。
- 句子以文字开头；显示公式按句子加标点。

## 示例

结论改写前（逐章小结）：

```
6 结论
第 2 章介绍了试验装置。第 3 章给出了 A、B 两种配方的测试结果。
第 4 章分析了温度的影响。第 5 章讨论了误差来源。
```

改写后（总体结论，含适用条件）：

```
6 结论
在 20 ℃～60 ℃ 范围内，B 配方的抗压强度比 A 配方高 12%（3 组重复，标准差 1.8%），
可以替代 A 配方用于【待补：工程部位】。60 ℃ 以上未测试，本结论不适用于该温度区间。
```
