# 学术论文、学位论文

## 适用

- 读者：
  - 学位论文：答辩委员会、评阅人，判断学生是否达到所申请学位的能力要求；学位授予单位和国家有关部门，保存和检索论文。
  - 期刊论文：本专业读者，据论文重复研究过程；二次文献和检索系统，按题名、摘要、关键词收录。
- 用在：博士、硕士、学士学位论文；投给学术期刊的研究论文。
- 不适用：
  - 科研项目的进展报告、专题报告、结题报告 → `tech-report.md`
  - 面向公众介绍研究成果的稿件 → `popular-science.md`
  - 标准、技术规范 → `standard.md`
  - Agent 完成任务后给用户的结果汇报 → `agent-report.md`

### 先定论文形态

动笔前定下面四件事，写进工作记录：

1. **论文类型**：学位论文（注明博士、硕士或学士）还是期刊论文。两类的必需章节、摘要字数、致谢位置都不同，下文分开写。
2. **学校或期刊细则**：向用户要学校的学位论文规范或期刊的投稿须知。国标只定基本规定，学科、学位类别、期刊可以在此基础上细化；细则有更具体的规定时按细则，并在工作记录里写明依据的是哪份细则。
3. **参考文献著录版本**：学校或期刊指定 GB/T 7714-2015 时按 2015 版，否则按 2025 版；工作记录里写明用的哪一版。
4. **撰写语言**：学位论文以中文为主；用外语写的学位论文，另写中文题名和中文摘要。

## 必需章节

### 学位论文

按下列顺序排列。

1. **封面**、**封二**（可选：学校有模板时按模板）。
2. **题名页**：中图分类号、学校代码、UDC 分类号、密级、学位授予单位全称、题名、责任者、申请学位、学科专业、研究方向、论文提交日期、培养单位。缺的写 `【待补：缺什么】`。
3. **英文题名页**（可选）。
4. **勘误页**（有则必备）：题名页之后另起页，顶部写题名、副题名、作者名。
5. **原创性声明**：在导师指导下独立完成；无抄袭、篡改、伪造、代写和买卖；引用和参考的内容都已标明出处。
6. **使用授权说明**：学位授予单位有权保存印刷本和电子版、提供检索阅览、向国家有关部门送交。学校有固定文本时照用学校文本。
7. **致谢**（有则必备）：可以单独成页放在摘要页前，也可以写进序言、前言或后记。
8. **中文摘要页**：摘要加 3～8 个关键词。
9. **英文摘要页**（宜有）：另起一页，放在中文摘要页后，下方写英文关键词。
10. **序言或前言**（有则必备：要交代研究缘起、背景、基金资助、编写体例时；也可以写进引言）。
11. **目次页**：另起页，放在序言、前言之后。
12. **插图清单、附表清单**（有则必备：图表较多时）：列序号、题名、页码，放在目次页后。
13. **缩写和符号清单、术语表**（有则必备）：集中放在图表清单后。
14. **引言（绪论）**：领域历史回顾、前人工作的综合述评、研究目的、研究流程和方法。
15. **主体**：章节划分由作者定。
16. **结论**：核心观点、研究局限、未来工作建议。
17. **参考文献**：正文后另起页。
18. **附录**（有则必备）：详细方法、过大的材料、罕见资料、原始数据、推导、数据集；读过但未引用的文献作为附录"参考书目"。
19. **索引**（可选）：放在附录后，按 GB/T 41210 编制。
20. **作者简历**（可选）：教育经历、攻读学位期间发表的论文和其他成果。

### 期刊论文

按下列顺序排列。

1. **题名**：中文题名，宜加外文（多为英文）题名。
2. **作者信息**：姓名、工作单位、通信方式，放在题名下；宜加外文作者信息；可以标通信作者。
3. **摘要**：放在作者信息之后。
4. **关键词**：3～8 个，放在摘要之后。
5. **其他项目**（基金资助论文必备）：基金名称及项目编号；宜标收稿日期，可以标修回日期、引用本文的格式、二维码等增强出版元素。
6. **外文摘要、外文关键词**（宜有）：放在中文摘要后，也可以放在文末。
7. **引言**：背景、目的、理由、预期结果和意义。
8. **主体**：理论分析、材料与方法、结果和讨论宜各自成章。
9. **结论**（有则必备；推导不出结论时改为"结束语"）。
10. **致谢**（可选）：排在结论或结束语之后，一般不编章编号。
11. **参考文献**。
12. **附录**（有则必备）：重要原始数据、数学推导、计算程序、设备的详细描述。

## 写作规则

摘要与关键词、参考文献著录、图表公式、章节与附录编号的共用写法见 `blocks/gbt7713-7714.md`，动笔前读。下文只写论文特有的部分。

章名用标准里的要素名（摘要、关键词、引言或绪论、结论、参考文献、致谢、附录），不按 base.md 改写成陈述句标题。

### 题名

- 题名写成名词性短语，一般不超过 25 字；层次多时拆成正题名加副题名。
- 题名用标准术语、学名全称、药物和化学品通用名称，不用不常用的缩略词、代号、公式、广义词和夸张词。
- 期刊论文只在三种情况下加副题名：正题名语义未尽、分篇或分阶段报道、其他必要的引申。
- 学位论文的题名中英文对照。
- 封面、题名页、摘要页等各处的题名逐字一致。

### 作者、导师与声明

- 学位论文的责任者写学生姓名、学号、导师姓名和专业技术职务；有校外导师的一并列出，导师组指导的列出全部导师；姓名拼音按 GB/T 16159。
- 期刊论文只把实际贡献者列为作者：参与选题和方案、直接参加主要研究并有贡献、参加撰写并能对内容负责。其他参与者写进致谢。
- 作者按贡献大小排序；集体成果列出全部作者姓名，不只写课题组名。
- 期刊论文中国作者姓名拼音按 GB/T 28039：姓前名后，双名连写，不加短横，名不缩写，如"Zhang Xiaoming"。
- 致谢写给基金、协助者、提建议者、授予转载引用权的权利人。

### 摘要

- 写成报道性摘要，篇幅主要给结果和结论，目的写一两句。
- 结果写出主要定量数据。
- 摘要能脱离正文单独读懂：首次出现的非公知简称、外文缩略语给出全称或中文解释。
- 不重复题名已有的信息，不写本学科的常识。
- 作者自写的摘要可以用"本文""笔者""我们"等第一人称。
- 字数按论文类型定：

  | 类型 | 字数 |
  | --- | --- |
  | 学位论文中文摘要 | 300～1000 字 |
  | 外语学位论文的中文摘要 | 不少于 5000 字 |
  | 期刊报道性摘要 | 约 400 字 |
  | 期刊报道-指示性摘要 | 约 300 字 |
  | 期刊指示性摘要 | 约 150 字 |

- 学位论文摘要只用文字，图、表、化学结构式移到正文。
- 期刊论文摘要可以含数学式、化学式、图、表，但不写它们的编号，也不写参考文献编号。
- 期刊论文摘要写成一段，只有需要另行居中排的式子或图表时才分段；学位论文摘要另页编排，可以分段。
- 一段式摘要段首写"摘要"二字；结构式摘要按目的、方法、结果、结论的顺序编排，要素名用黑体或【】标出。期刊有自己的格式时按期刊。
- 英文摘要与中文摘要内容对应，可以比中文多含信息。
- 期刊论文写英文摘要时，题名、作者姓名、作者单位、关键词一并译成英文，与英文摘要连续编排。
- 学位论文中文摘要末尾可以注"图×幅，表×个，参考文献×篇"。

### 关键词

- 关键词的数量、出处、选词和位置见 `blocks/gbt7713-7714.md`。
- 选能表示论文主题、有检索意义的专业术语；"方法""理论""分析"这类泛指词换成具体的方法名或对象名。
- 词表未收的新学科新技术术语、地区名、人名、产品名可以直接用。

### 引言、主体、结论

- 引言客观评介前人研究，写明本文的创新点，如实区分前人成果和作者自己的成果。
- 学位论文按学位层次写贡献：博士论文表明创新性成果和独立研究能力，硕士论文表明从事学术研究或承担专业实践的能力，学士论文表明初步的研究能力。
- 主体写到本专业读者能据此重复研究：理论、假设、方法、工艺、程序、参数选择，关键设备、仪器、材料和研究对象。
- 结论写成对全文的总体判断，不重复摘要，不逐章罗列各章小结。
- 学位论文的结论单列研究局限和未来工作建议。
- 期刊论文的结论编章编号；推导不出结论时写"结束语"，提出讨论、建议或待解决的问题。

### 引用与参考文献

- 著录规则见 `blocks/gbt7713-7714.md`。
- 读过但未引用的文献，学位论文放进附录"参考书目"。
- 只引与本文主题密切相关的文献。
- 期刊论文用顺序编码制时，参考文献表放在文末，也可以用脚注放在当页地脚。
- 没有文献来源、只需补充说明的内容写成脚注，脚注编号与参考文献的圈码编号区分开。

### 图、表、公式

- 图表公式的共用写法见 `blocks/gbt7713-7714.md`。
- 坐标轴标目和表格栏目写成"量的符号或名称/单位符号"，如"t/s"。
- 表头不画斜线；相同内容在每格重复写出或合并成通栏，不写"同左""同上"。
- 表内空白表示无此项或未测，"—"表示测过但未发现，"0"表示实测为零；三者按此区分。
- 只有 1 幅图或 1 个表时也编为"图 1""表 1"。
- 公式另行起排；两个以上公式时依次编号。
- 正文行文中的分数降为一行，用"/"或负指数表示。
- 长公式在关系符号或运算符号之后断开转行，下一行开头不重复该符号。
- 用量符号表示量，不用量的名称或多字母缩略语代替。

### 量、单位与数字

base.md 已管数值写法、单位空格、词头。论文另加：

- 量符号用斜体，pH 除外；单位符号用正体。
- 不把 rpm、kmph、bps、ppm 当单位符号，改用法定计量单位的符号。
- 几个量值相乘时，每个量值都写单位，如"20 mm × 30 mm"。
- 百分数范围两端都写"%"，如"10%～20%"。
- 有效数字全部写出：测到 1.50 就写 1.50，不写 1.5；修约按 GB/T 8170。

### 编号与版式

- 章节标题一般不超过 15 字，末尾不加标点；同一层级的节要么都有标题，要么都没有。
- 列项用 a)、b) 或 (a)、(b)；(1)、(2) 已用于公式编号时，不再用于列项。
- 附录的编号和标题各占一行居中，每个附录另起页。
- 学位论文页码：前置部分（封面除外）用罗马数字单独编页，正文和后置部分用阿拉伯数字连续编页。
- 学位论文正文从另页右页开始，每章另起页。
- 学位论文印刷本用 A4 纸，天头和订口留 25 mm 以上，地脚和切口留 20 mm 以上；书脊写正题名和学位授予单位。
- 期刊论文的字体字号按期刊要求；7713.2 附录 B 只是建议。

## 示例

期刊论文摘要，改写前（指示性，有评论，重复题名）：

```
摘要：本文对基于深度学习的路面裂缝检测方法进行了研究，提出了一种新颖的方法，
并进行了大量实验，结果表明该方法具有很好的效果，具有重要的应用价值。
关键词：深度学习；裂缝；方法；研究
```

改写后（报道性，结果有数据）：

```
摘要：为减少路面裂缝人工巡检的漏检，提出一种融合多尺度特征的分割网络。在
【待补：数据集名称】的 2 000 幅图像上训练和测试，F1 值为 0.87，比 U-Net 高 4.2 个
百分点，单幅推理时间 35 ms。网络对宽度小于 2 mm 的裂缝仍有漏检。
关键词：路面裂缝；语义分割；多尺度特征融合；U-Net
```
