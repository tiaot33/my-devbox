# 内容块：图、表、公式

## 适用

- 用在：文档里有对比、参数清单、条件组合、数据、示意图或公式时。
- 不适用：
  - 画图表本身（选图形、配色、坐标轴）→ `dataviz`。
  - 科技报告、学术论文的编号和版式 → `blocks/gbt7713-7714.md`。

## 写作规则

### 表

- 用表格写三类内容：多个对象按相同维度比较、参数或配置清单、条件组合。只有一列的表改成列表。
- 第一列放比较对象，其余每列一个维度；行按读者查找的顺序排，如字母序、频率或时间。
- 单元格只放短语和数值；单位写在表头，如"超时（ms）"；空格子写"—"或"不适用"，不留空。
- 一个单元格要写两句以上、或要放列表时，这一项改写成小节。
- 表前一句写读者从表里能得出的结论，如"三个方案里只有 B 能在大促前完成"；不写"下表列出……""下表用来查……"。小节标题已经说明表的内容时，省略这一句。

### 图

- 图放在首次提到它的段落之后，正文写出读者应从图里看出的结论，不只写"见下图"。
- 图片的替代文字写出图要传达的信息，不写"示意图""截图"。
- 截图只配合文字步骤用，读者不看截图也能照文字操作。
- 流程图、架构图、时序图优先用目标平台能渲染的文本格式（如 Mermaid），不能渲染时用图片并保留源文件。

### 公式

- 公式下方写出每个符号的含义和单位。
- 行内公式和独立公式用目标渲染器支持的写法；不确定时问用户，或写成代码块里的纯文本。
- 只有被正文引用的公式才编号。

### 编号与引用

- 同类图表有 3 个以上，或正文要引用某一个时，按"图 1""表 1"连续编号；只有一两个且不引用时不编号。
- 引用写编号和内容："见表 2'各方案延迟对比'"。
- 表题放在表上方，图题放在图下方；题目末尾不加句号。

## 审查清单

- [ ] 每张表都属于比较、清单、条件组合三类之一，没有单列表格。
- [ ] 每个表头带单位（有单位时），没有空单元格。
- [ ] 没有单元格里写两句以上或放列表。
- [ ] 每张图后面的正文写了读者应看出的结论。
- [ ] 每张图都有写出信息的替代文字。
- [ ] 每个公式下方解释了全部符号和单位。
- [ ] 编号的图表都被正文引用了，引用写了编号和内容。
- [ ] 没有"下表列出……""下表用来查……"式的引导句。
