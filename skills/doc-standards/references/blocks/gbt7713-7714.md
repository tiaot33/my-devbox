# 内容块：GB/T 7713 系列文档的共用写法

## 适用

- 用在：按 GB/T 7713 系列写的科技报告、学位论文、期刊论文，其中的摘要与关键词、参考文献著录、图表公式、章节与附录编号。
- 不适用：
  - 一般文档里的图、表、公式 → `blocks/figure-table.md`
  - 一般文档里的引用来源 → `blocks/citation.md`

## 写作规则

### 摘要与关键词

- 摘要写目的、方法、结果、结论四项，不加评论和补充解释。
- 关键词 3～8 个，另起一行放在摘要下方。
- 每个关键词在题名、摘要或正文中有明确出处。
- 优先用《汉语主题词表》或本专业主题词表中的规范词。
- 写出与中文关键词一一对应的英文关键词。

### 参考文献与著录

- 正文引用的每篇文献都列入参考文献表，表里的每篇文献都被正文引用过。
- 顺序编码制和著者-出版年制选一种，全文统一。用著者-出版年制时，参考文献表按著者字顺和出版年排序。
- 按 GB/T 7714-2025 已确认的变化著录：
  - 西文著者姓氏只大写首字母，如 `Einstein A`。
  - "普通图书"改称"图书"。
  - 标准的文献类型标识 `[S]` 可以省略。
  - 责任者 3 个以内全部写出；超过 3 个时写前 3 个，后加"等"或"et al"。这里的"等"是著录格式要求，不按 `base.md` 删去。
  - 预印本标 `[PP]`，数据集标 `[DS]`，网站和网页标 `[EB]`。
  - 在线资料先按本身的文献类型著录，`[OL]` 只表示获取方式，如在线期刊论文写 `[J/OL]`，并写访问路径和 DOI；URL 已含 DOI 时不重复写。
  - 网页、数据集、预印本写发布或修改日期、引用日期，访问路径指向具体资源，不指向平台首页。
  - 非网络文献不写访问日期。
  - 引用学位论文时写具体的引用页码。
- 拿不准的著录细节写 `【待补：按 GB/T 7714-2025 核对著录格式】`，不按 2015 版推测。

### 图、表、公式

- 图号和图题放在图下方，表号和表题放在表上方；表格用三线表。
- 图表紧跟首次提到它的段落，先有文字后有图表。
- 照片带尺寸标度。
- 图或表跨页时，续页标"续图×""续表×"，表也可以标"表×（续）"；续表重复表头。
- 图、表、公式分别用阿拉伯数字连续编号，如图 1、表 2、式(3)。大中型报告和学位论文可以分章编号，用半字线，如图 2-1、式(3-1)。全文只用一种编号方式。
- 公式编号写在公式行最右端并右对齐，只写 (3)，括号用半角，与公式内的括号一致；正文引用时写"式(3)"。
- 公式下方紧接着解释每个符号的含义和单位。

### 章节与附录编号

- 章节标题用阿拉伯数字分级编号，如 1、1.1、1.1.1，末位后不加点，一般不超过 4 级。章编号全文连续，节编号在所属章内连续。
- 引言可以编为 0；标题不写"引言"二字时不编 0。
- 附录用大写拉丁字母编号并带标题。

## 审查清单

- [ ] 摘要含目的、方法、结果、结论四项，没有评论和补充解释。
- [ ] 关键词 3～8 个，每个在题名、摘要或正文里有出处；中英文关键词数量相同、一一对应。
- [ ] 正文引用的每篇文献都在参考文献表里，表里的每篇文献都被正文引用过。
- [ ] 全文只用一种引文标注制式。
- [ ] 西文著者姓氏只大写首字母；超过 3 个责任者的只列前 3 个加"等"或"et al"。
- [ ] 非网络文献没有访问日期；网页、数据集、预印本有发布或修改日期和引用日期。
- [ ] 没有按 2015 版推测的著录细节；拿不准的写了【待补】。
- [ ] 图题在图下方，表题在表上方，表格是三线表。
- [ ] 续表标了"续表×"或"表×（续）"，并重复了表头。
- [ ] 图、表、公式各自连续编号，没有跳号和重号，全文只用一种编号方式。
- [ ] 公式编号写成 (3)，编号前没有"式"字；公式下方解释了全部符号和单位。
- [ ] 章节编号是阿拉伯数字分级，不超过 4 级；附录用大写拉丁字母编号并带标题。
