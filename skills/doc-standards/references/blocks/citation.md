# 内容块：引用来源

## 适用

- 用在：文档引用了外部事实、数字、原话、标准或他人观点，且读者可能要核对或深入阅读时。
- 不适用：学术论文、科技报告的参考文献著录 → `blocks/gbt7713-7714.md`。

## 写作规则

- 只引读者需要核对或深入阅读的来源；作者参考过但读者用不到的不列。
- 出处紧跟在它支撑的那句话后面，链接文字写来源名称："据《Go 1.22 发布说明》"，不写"这里"。
- 原话加引号，一字不改；转述不加引号。
- 来源有版本时写版本：标准写"编号:年份"，软件写版本号，网页写页面更新日期；没有更新日期时写访问日期。
- 只从二手资料读到的，写"据 B 转引 A"，不写成直接引自 A。
- 来源说法互相矛盾时，并列写出各自的说法和来源，不替读者选边；作者有判断时单独一句，标明是作者判断。
- 来源多于 3 个时，文末加"参考"一节，按正文首次出现的顺序编号，每条写：作者或机构、标题、版本或日期、链接。

## 审查清单

- [ ] 每个外部数字、原话、标准要求都紧跟着出处。
- [ ] 每个链接文字写出了来源名称。
- [ ] 引号内是原话，转述没有加引号。
- [ ] 每个来源写了版本、更新日期或访问日期。
- [ ] 二手来源都写成了"据 B 转引 A"。
- [ ] 来源多于 3 个时有"参考"一节，编号和正文首次出现的顺序一致。
