# 内容块：命令与代码示例

## 适用

- 用在：文档里任何给读者复制、运行或参照的命令、代码、配置。
- 不适用：给出语法格式或声明的代码块，如命令语法、API 参考"声明或语法"一节里的签名和路径模板。语法格式单独放在前面写着"语法："的 `text` 代码块里，可以用语法记号和 `{project_id}` 这类路径模板。

## 写作规则

### 代码块

- 用代码围栏（```）并标注语言；改写原稿时，四空格缩进的代码块改成代码围栏。
- 引出命令时写命令做什么，如"安装依赖："，不写"运行以下命令："。
- 示例前写引导：演示什么场景、代码里看不出的要点、运行所需的依赖和环境。引导紧挨示例时以冒号结尾。
- 先给最简单的常见用法，再逐步加复杂度；复杂的多步场景链接到教程。
- 输入和输出分成两个代码块。命令有文本输出时，用"输出类似以下内容："引出输出代码块；没有文本输出时，写明运行后得到什么结果，如生成了哪个文件。
- 输出里每次都不同的值（时间戳、ID），换成占位符，或在代码块后说明哪部分会不同。
- 每行不超过 80 个字符；更长的命令在合适的字符前断行，续行缩进四个空格。

### 复制后能运行

- 可复制的命令和代码，复制后只替换占位符就能运行。
- 可复制的代码里不放作语法记号的 `[]`（可选）、`{}` 和 `|`（必选其一）、`...`（可重复）；代码本身的管道、JSON、数组、`./...` 通配、`find -exec {}` 照写。
- 路径模板里的 `{project_id}`，在可复制的命令里换成占位符 `PROJECT_ID`。
- 省略的代码用该语言的注释标出，如 `# 此处省略连接配置`，不用 `...` 或省略号；含省略的代码块不标为可复制。JSON 这类没有注释语法的格式不省略，写一个最小的完整值，如只含一个元素的数组。

### 占位符与机密

- 占位符写法：项目已有约定时跟随；没有约定时用全大写加下划线，如 `PROJECT_ID`，不加 `MY_`、`YOUR_` 前缀。项目主风格指南是 Microsoft 时，代码里用尖括号，如 `<project-id>`；shell 命令里仍用全大写，因为尖括号在 shell 里是重定向符。全文只用一种写法。
- 在代码块后逐个说明占位符：只有一个时写"把 `API_KEY` 替换为……"；多个时用"替换以下内容："引出列表，按出现顺序排列。
- 密码、令牌、密钥写成环境变量，如 `$API_TOKEN`，或写成占位符，不写真实值。环境变量不算占位符，在前置条件里说明怎么设置。

### 正确性

- 示例按安全写法写，如校验用户输入。只在异常处理本身是示例要演示的内容时写异常处理；不捕获因参数非法而抛出的异常。
- 示例按项目其余代码的 lint 规则检查。
- 交付前运行每个示例和命令。没有运行条件时，在交付说明里列出未实测的示例和所在章节，正文不加标记。

## 审查清单

- [ ] 代码块都用代码围栏并标了语言。
- [ ] 每条命令前写了它做什么，没有"运行以下命令"。
- [ ] 输入和输出在不同代码块里；有文本输出的，输出前有"输出类似以下内容："，没有的写了运行结果。
- [ ] 可复制的代码里没有作语法记号的 `[]`、`{}`、`|`、`...`，路径模板已换成占位符。
- [ ] 省略的代码用语言注释标出，含省略的代码块没有标为可复制；JSON 里没有 `...`。
- [ ] 全文只用一种占位符写法，shell 命令里没有尖括号占位符；每个占位符在代码块后有说明。
- [ ] 没有真实的密码、令牌或密钥；用到的环境变量在前置条件里说明了怎么设置。
- [ ] 每行不超过 80 个字符。
- [ ] 每个示例和命令都已运行，或已在交付说明里列为未实测。
