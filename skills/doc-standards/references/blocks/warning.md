# 内容块：警告与风险提示

## 适用

- 用在：文档里任何读者不按顺序做、做错或做了无法撤销，会造成损害的地方，包括数据丢失、服务中断、环境损坏，以及教程、SOP、测试规程里的风险步骤。
- 实体产品的安全信息（人身伤害、信号词、安全标志、安全消息的分级和位置）：另按 `user-manual.md`"安全信息"，该节的写法优先。
- 警告里的步骤和命令按 `blocks/steps.md`、`blocks/code-sample.md` 写。

## 写作规则

- 不按顺序做会造成损害时，把"先确认什么、不得做什么"写在对应操作之前。
- 警告第一句写必须做或不得做的事，第二句写不遵守的后果。
- 不可逆或有风险的操作，在这一步之前写明后果和回退办法（恢复或重来的办法）。

## 审查清单

- [ ] 有损害风险的操作，警告写在操作之前，且第一句是必须做或不得做的事。
- [ ] 每个不可逆操作之前都写了后果和回退办法。
