# 用户手册、使用说明、安全须知

## 适用

- 读者：安装、操作、维护、清洁、拆解产品的人。他们边读边做，或出了问题时来查；其中有弱势使用者（老人、儿童、阅读能力受限者、残障人士），受伤风险更高。
- 用在：硬件、机械、家电、消费品、软硬结合产品和应用软件的使用信息，覆盖运输、组装、安装、调试、操作、监控、故障排除、维护、维修、退役、处置各阶段；也用于单独成册的安全须知，以及随实体产品附带的快速安装指南、快速入门卡。机械产品先满足 ISO 20607，其余产品以 82079-1 为通用依据；纯软件的帮助文档可以叠加 26514。
- 不适用：
  - 软件或服务以学会一项任务为目的的快速入门、教程、操作指南 → `tutorial.md`
  - API、SDK 的参考文档 → `api-reference.md`
  - 代码仓库的 README → `readme.md`
  - 保修条款、用户协议、隐私政策正文 → `legal-terms.md`
  - 召回、停用通知和其他对外通知 → `public-notice.md`

## 必需章节

下列章节合并自 ISO 20607:2019 表 1（示例模板，5.1 说明不必全部包含）和 IEC/IEEE 82079-1:2019 第 7 章（多为"适用时"）。章节名作为固定标题使用。按文档形式取舍：

- 面向单一读者群的分册：删掉与这类读者无关的章节，其余可按下列顺序排。
- 单独成册的安全须知：保留第 1、3、4 章，第 3 章只写安全标志和信号词；封面写明配套使用说明书的名称或编号。
- 单页说明、快速安装指南、快速入门卡：各章可以并成小节，第 1、4、8 章的内容和相关安全消息必须保留。

1. **封面与标识**：文档类型（如操作手册、维护手册）、版本号、发布日期；产品型号，以及确定适用范围所需的信息（序列号段、适用期）；制造商名称和联系方式。分册时每册必须有封面，并标明"第 x 册，共 y 册"。
2. **目录**（可选：超过 12 页时必须有）：最多 4 级。
3. **本手册的用法**：目标读者，以及他们需要具备的能力或培训；版式约定（按键、菜单项、使用者输入内容的字体）；手册里和产品上出现的每个安全标志、图形符号、产品标签的含义；所用信号词的定义和中英对照（见"安全信息"）；缩略语和术语表；提醒读者妥善保留手册。
4. **安全须知**：集中放在手册开头，标题点明是安全内容（如"安全须知"）。按危险分小标题，每项写危险类型、危险来源、不遵守的后果、规避措施，适用时写事故发生后怎么处置。
5. **产品说明**：预期用途；可合理预见的误用；组成部件；关键规格；每个控制件和显示件的作用。
6. **运输、搬运与储存**（可选：需要使用者自己搬运、存放或重新包装时）：重量、吊装点、储存条件。
7. **安装与调试**（可选：需要使用者自己安装时）：包括安全系统检查和安装完成后的检查。
8. **操作**：运行模式、启动和停止、操作顺序，并且单独写异常情况和紧急情况下怎么做。
9. **信号与报警**：产品上每个指示灯、提示音、报警、屏幕状态各表示什么，读者看到后该怎么做；软件产品写状态提示和通知。表示故障的信号在本章只写含义，"怎么做"指向第 11 章排故表的对应行。
10. **维护与清洁**：普通使用者能做的和必须由专业人员做的分开写，各写明所需工具和方法。
11. **故障排除与维修**：单独成节，用排故表列出现象、可能原因、处理方法；软件产品列出错误消息及处理办法；最后给技术支持的联系方式。
12. **附件、耗材与备件**（可选：有可更换零件时加）：备件清单，每项给出产品上的名称和编号、制造商零件号；可以配爆炸图。
13. **拆解、回收与处置**（可选：实体产品加）：停用、拆解的步骤和废弃处理方式。
14. **信息安全与数据隐私**（可选：产品联网或保存使用者数据时加）：怎么使用数据保护相关功能，已知的 IT 安全漏洞和应对办法。隐私政策只给链接，正文 → `legal-terms.md`。
15. **索引**（可选：篇幅长、内容复杂时加）。

## 写作规则

### 动笔前

- 先向用户要产品风险评估中的残余风险清单，并要每项的严重程度（可能致死或重伤 / 轻度或中度伤害 / 只损坏财物），据此选信号词。清单里每一项写一条安全消息；"使用时注意安全"这类笼统提醒，改写成针对具体危险的安全消息。
- 拿不到清单时，按产品类型列出候选危险，每条写危险来源、后果和推测的严重程度，照常写成安全消息，并标 `【待确认：来自推断，非风险评估】`；在交付说明里请用户逐条确认。这与 base.md"来源没给的不补"不同，因为留空会交出一份没有安全消息的手册。
- 一册手册面向多类读者时，按读者群分章，章标题写明对象，例如"维护（仅限专业人员）"。
- 产品含第三方部件时，把供应商说明中的相关内容并入正文，或者附上供应商原文的相关部分，并在正文对应位置写明见哪一份。

### 安全信息

- 本文件用"安全消息"（safety message）统称所有安全相关的提示，"警告"只作 WARNING 的中文信号词。安全消息分三层放：开头集中的安全须知；某一节开头、适用于整节的章节安全消息；紧挨在危险步骤之前的嵌入式安全消息。安全须知用描述句写，信号词只用在章节安全消息和嵌入式安全消息里。按危险的位置选层级，不必每层都有。
- 每条章节安全消息和嵌入式安全消息按这个顺序写：信号词、危险类型和来源、不规避的后果、规避措施。这与 `blocks/warning.md` 的两句写法不同，产品手册按本条写；自查时该块清单"警告写在操作之前，且第一句是必须做或不得做的事"的后半句标"不适用：按 user-manual 四要素顺序"。其余规则（先警告后操作、不可逆操作写明后果和回退办法）同样适用。
- 危险贯穿整个步骤序列时，安全消息放在准备段；只涉及某一步时，放在这一步之前。
- 嵌入式安全消息不超过两行，以信号词开头，单独成段。
- Markdown 输出时，每条章节安全消息和嵌入式安全消息写成引用块：首行以加粗的信号词开头，写危险和后果；规避措施另起一行，以"→"开头。颜色和标志交给排版，在交付说明里注明。
- 风险评估没给严重程度时，按最坏的可信后果选信号词，并在安全消息后写 `【待补：确认严重程度】`。
- 按严重程度选信号词，全文只用一套定义体系，并在"本手册的用法"里写出所选体系的定义：

  | 信号词 | ISO 3864-2:2016 | ANSI Z535.6（2006 版定义） |
  | --- | --- | --- |
  | DANGER | 迫近的危险情况，不避免将导致死亡或重伤 | 危险情况，不避免将导致死亡或重伤 |
  | WARNING | 潜在危险情况，不避免可能导致死亡或重伤 | 危险情况，不避免可能导致死亡或重伤 |
  | CAUTION | 潜在危险情况，不避免可能导致轻度或中度伤害 | 危险情况，不避免可能导致轻度或中度伤害 |
  | NOTICE | 无此级 | 只用于与人身伤害无关的情况，如财产、设备损坏 |

- 只涉及财产或设备损坏的安全消息用 NOTICE 一级，不配安全警示三角符号。
- 软件手册按 26514 写时，CAUTION 还包括数据丢失和设备问题，这与 ISO 3864-2 的定义不同。
- 中文手册的信号词，按用户的公司规范；没有规范时用：危险＝DANGER、警告＝WARNING、注意＝CAUTION，提示＝NOTICE（国标没有这一级，本文件的选择）。"注意""提示"只作信号词，正文其他地方不用作提示词。
- 彩色印刷时，严重度面板用红底白字表示 DANGER、橙底黑字表示 WARNING、黄底黑字表示 CAUTION，橙色只给 WARNING。黑白印刷时颜色无法区分级别，本文件要求写出信号词。
- 产品可能被儿童、老人或其他弱势使用者接触时，在安全须知里写明谁不得使用、谁必须在看护下使用；年龄限制取自风险评估或认证要求，拿不到时写 `【待补：使用者年龄限制】`。

### 操作步骤

- 每个步骤序列分三段：准备（目的、前提条件、所需人员、工具、材料、密码，以及适用于整个序列的安全消息）→ 编号步骤 → 完成（读者凭什么判断已经做成，下一步去哪一节）。
- 编号步骤按 `blocks/steps.md` 写，本节只写实体产品另加的要求。
- 安全消息的通用写法见 `blocks/warning.md`，本文件"安全信息"一节另加的要求优先。
- 某一步可能出错时，在这一步下面写出错时会看到什么、怎么处理，或者指向故障排除表的对应行。结果句和出错提示写在同一编号项内，不另编号；这不算 base.md 的"步骤和描述混在同一列表"。
- 任务小节的标题用"动词+对象"，如"清洁刀片"；这是 base.md 标题规则的例外。

### 内容取舍与载体

- 产品宣传和营销话术移出手册。
- 插图配文字说明，与说明文字排在同一视野内；需要插图而拿不到时，写 `【待补：插图，内容是……】`，图注和说明文字照常写。用颜色表示的信息，同时用文字或形状表示。
- 使用信息印在包装以外的载体上；产品无法开机时读者仍需要的内容（安装、故障排除、恢复、客服联系方式）必须放在不依赖产品本身的载体上。
- 纸质版每页有页码，在排版时加；输出 Markdown 时，页码一项标"不适用：交给排版"，页数无法确定时给目录。
- 纸质版引用网上资料时写完整网址，可以加二维码；电子版必须能全文搜索。

### 英文手册

- 信号词全部大写加粗，放在一般警告标志右侧；这是 base.md"不用全大写"的例外。

## 审查清单

审模式分三步：

1. 对照"必需章节"查完整性。
2. 对照"写作规则"做桌面检查。
3. 在报告里建议用户安排经验性测试：让不熟悉产品的人照着手册实际操作。消费品必须做这一步。

产品本身的缺陷单独列出，不算手册问题。

拿不到风险清单或产品资料时，"残余风险"和"指示灯"两条标"无法判定"，并列出从文档推断出的可能危险和信号，请用户核对。

完整性：

- [ ] 封面有文档类型、版本号、发布日期、产品型号和适用范围、制造商联系方式
- [ ] 分册时每册封面都有"第 x 册，共 y 册"
- [ ] 超过 12 页或页数无法确定的手册有目录；纸质版每页有页码
- [ ] 写明了目标读者及其所需能力
- [ ] 写明了预期用途和可合理预见的误用
- [ ] 每个控制件和显示件都写了作用
- [ ] 产品上的每个指示灯、提示音、报警都有含义和应对说明
- [ ] 操作章节单独写了异常和紧急情况
- [ ] 维护章节把普通使用者能做的和专业人员做的分开，各写了工具
- [ ] 有故障排除表，并给出了技术支持联系方式
- [ ] 有可更换零件的产品附了备件清单
- [ ] 实体产品写了拆解、回收与处置
- [ ] 联网或保存使用者数据的产品写了数据保护功能的用法和已知漏洞的应对
- [ ] 第三方部件有并入的说明，或写明了供应商原文在哪里

安全信息（见写作规则"动笔前""安全信息"）：

- [ ] 安全须知集中在手册开头，标题点明是安全内容
- [ ] 残余风险清单里的每一项都有对应安全消息；没有清单时，推断出的每条都标了 `【待确认：来自推断，非风险评估】`
- [ ] 没有"注意安全""小心操作"这类不指明具体危险的提示
- [ ] 每条章节安全消息和嵌入式安全消息都按信号词、危险类型和来源、后果、规避措施的顺序写全四项
- [ ] 每条安全消息都在相应步骤或步骤序列之前
- [ ] 嵌在步骤中间的安全消息都不超过两行
- [ ] 集中安全须知里没有用信号词
- [ ] 每个信号词都与所选体系的定义对得上（例如可能致死的危险没有用 CAUTION）
- [ ] 全文只用一套信号词体系和一套中文译法，"本手册的用法"里写出了定义和中英对照
- [ ] "注意""提示"只作信号词出现
- [ ] 只涉及财产损坏的安全消息没有配安全警示三角符号
- [ ] 手册里和产品上出现的每个安全标志、符号、产品标签都有解释
- [ ] 弱势使用者可能接触的产品，写明了谁不得使用、谁必须在看护下使用

操作步骤（见写作规则"操作步骤"）：

- [ ] 每个步骤序列都有准备、编号步骤、完成三段，完成段写了读者如何判断已做成
- [ ] 编号步骤逐条通过了 `blocks/steps.md` 的审查清单
- [ ] 安全消息逐条通过了 `blocks/warning.md` 的审查清单（第一句的要求按本文件四要素顺序）
- [ ] 任务小节的标题是"动词+对象"
- [ ] 面向不同读者群的内容分章，章标题写明了对象

内容与载体（见写作规则"内容取舍与载体"）：

- [ ] 没有产品宣传和营销话术
- [ ] 用颜色区分的信息另有文字或形状
- [ ] 安装、故障排除、恢复、客服联系方式在不依赖产品本身的载体上
- [ ] 纸质版引用的网上资料写了完整网址

## 示例

改写前：

```markdown
注意安全，小心操作。
1. 关闭切片机并拔掉电源插头。
2. 机器停止。
3. 用刷子清洁刀片。
```

改写后：

```markdown
准备：随附的刷子、防割手套。
> **警告** 刀片锋利，转动或惯性转动时接触会割伤手指，可能导致断指。
> → 拔下电源插头，等刀片完全停止后再操作。
1. 关闭切片机。
2. 拔下电源插头。刀片逐渐停止转动。
3. 等刀片完全停止。
4. 戴上防割手套。
5. 用刷子从刀片中心向外刷。

完成：刀片表面无残渣。接着装回护罩（见 5.3 节）。
```
