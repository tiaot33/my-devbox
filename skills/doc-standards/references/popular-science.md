# 科普文章

## 适用

- 读者：教育背景、经历、兴趣各不相同的普通读者，从中小学生到企业和政府的决策者。科协指南三列出的重点受众是青少年、农民、产业工人、老年人、领导干部和公务员、非本专业科技工作者。
- 用在：向公众解释科学的报刊和网络文章、科普专栏、健康科普文章。按内容分三种，必需章节按种类取舍：
  - **原理解释**：讲基础学科的概念和原理，如"天为什么是蓝的"。
  - **成果解读**：讲一项研究成果、一项技术的应用或前沿进展。
  - **辟谣与行为建议**：纠正一种错误说法，或建议读者采取某种行为，如"蓝光会不会让人失眠"。
- 健康科普：以健康领域的科学知识、方法、技能为内容，帮读者形成健康观念、采取健康行为的稿件。讲疾病、用药，或就饮食、睡眠、运动、用眼给建议的，都算。三种文章都可能是健康科普，另按"健康科普"一节和必需章节第 8 项写。
- 不适用：
  - 专家写给同领域专家的期刊论文、学位论文：24495-3 不专门处理这类写作（第 1 章）→ `thesis.md`
  - 机构发布研究成果的新闻稿 → `public-notice.md`；稿件里解释科学内容的段落，按本文件"科学性""术语与解释"两节写。
  - 以推广产品为目的的软文：告诉用户本文件不覆盖；健康类的，说明健康科普不含商业信息，问用户是否改写成不含推广的科普。
  - 向资助方或主管部门报告研究过程和结果 → `tech-report.md`
  - 给阅读困难读者的易读版 → `register/easy.md`
  - 教读者一步步操作的指南 → `tutorial.md`

## 必需章节

1. **标题**：用全称和日常词，让领域外的读者一看就知道讲什么；读者人人都懂的缩写（如 AI、DNA）可以直接用。
2. **开篇**：开篇段写出新发现或核心结论，接着写读者为什么要在乎。可以先用案例、设问或悬念引入，结论紧跟在引子后面；这是对 `base.md`"每段第一句写本段要点"的例外，只限开篇段。成果解读还要在开篇段写明研究出处（期刊论文、机构报告）。
3. **主体**：围绕三个要读者记住的要点组织，排列顺序见"结构"一节。
4. **局限与争议**（可选：成果解读时加；原理解释、辟谣与行为建议在话题有局限、风险或学术争议时加）：写出所讲内容目前的局限、潜在风险、伦理问题，以及学界的不同看法和各自依据。
5. **规范与边界**（可选：话题涉及政策法规、行业标准或伦理边界时加）：写出相关的法规、标准或伦理要求。
6. **结尾**：成果解读写发展方向和对社会的影响；原理解释回到开篇的问题，或写这个原理在生活里的用处；辟谣与行为建议写读者可以怎么做、为什么这样做。
7. **来源与署名**：列出引用的论文、数据、图片的出处。写明作者、审核者及其身份、发布日期，修订过的写修订日期。
8. **健康提示**（可选：健康科普时加）：写明这些信息适合哪些人（适宜人群或目标人群）；养生保健类内容另说明不能替代医生的治疗或医嘱。

## 写作规则

### 篇幅与读者

- 用户给了篇幅时按用户的。没给时，聚焦单一话题的短文 500～1500 字，深度解读复杂原理或成果的长文 1500～5000 字。
- 写给老年人时，用短文篇幅，要点突出，图文结合；写给非本专业科技工作者时，保留准确严谨的表述，信息密度可以更高。

### 科学性

- 简化表述时保持准确和精确：换成通俗说法后，回头核对这句话在科学上是否仍然成立；不成立就保留原术语再解释。
- 每个事实、数据、结论都能追到一份权威来源：同行评议的论文，政府或权威机构的标准、指南、报告。在工作记录里建一张资料台账，逐条记下出处和发表日期；台账附在交付说明里交给用户，不进正文。
- 写出每条信息的确定程度：科学共识照共识写；专家个人观点写出专家的姓名和单位或身份；单项新研究写明"这是一项新研究的结果"，并写出发表在哪里。
- 成果的适用范围和确定程度照原始文献写：文献说"在小鼠身上""初步结果"，正文就写出来。
- 标题和正文用原始文献里的说法描述成果："突破""彻底""攻克""治愈""首次""颠覆"只在文献支持时用；标题写出成果是什么，不用"重磅""震惊"这类情绪词。
- 引用来源按 `blocks/citation.md` 写，但来源列表按本文件的"来源与署名"一节写，不另加 `blocks/citation.md` 的"参考"一节；每个统计数据和研究结果都在来源列表里有对应条目，条目写出年份。
- 提到伪科学说法时，紧接着写出它错在哪里和正确的说法。

### 术语与解释

本节比 `base.md` 更严：`base.md` 允许保留专用词并在首次出现处定义；科普文章先考虑换掉。

- 能用日常说法讲清的，直接用日常说法，不出现术语。如 AAAS 的例子：用 "break open cells"（把细胞打破）代替 "induce lysis"（诱导裂解）。
- 读者以后还会遇到、必须保留的关键术语，首次出现时紧跟一句通俗解释；解释要简短，不写成教科书定义。
- 抽象原理用比喻、类比或生活场景解释。
- 一个词在不同学科或日常语言里意思不同时（如"显著""理论"），用到时写明本文取哪个意思。
- 开篇段只放核心结论用到的一个数字；其余数字、缩写和测量值放到主体。读者人人都懂的缩写不受此限，同 `base.md`。

### 结构

- 按"结论→为什么重要→支撑细节"排列，不套用论文的"背景→方法→结果"。
- 讲科研故事和科学家事迹时，用它展示科学方法和科学思维，如实证、质疑。

### 图像与数据

- 图的位置、替代文字和编号按 `blocks/figure-table.md` 写。
- 每张图都用来解释正文里的一个新概念或背景原理。
- 图注写成能脱离正文独立读懂的完整说明。
- 用到人物肖像或涉及个人隐私时，取得授权，并在交付说明里写明授权情况。

### 健康科普

- 内容以循证医学证据和现行医学共识为准，优先引用政府和权威机构的指南。
- 提到药品、器械时写通用名，不点名品牌和机构。
- 说某种疗法或保健做法有效、无效时，附上科学依据。
- 建议读者采取某种行为时，写出为什么做、怎么做，并确认这个行为在读者条件下做得到。措辞按 `base.md`"受控情态词"里表达建议的一条，写出理由或适用条件。
- 写疾病风险时，写出具体的风险大小和应对办法，让措辞不因含糊或有歧义引起恐慌或伤害。

### 大模型辅助写作

agent 写稿本身就是大模型辅助创作，下面几条直接适用：

- 每条事实、数据、引文都用权威文献交叉核对；核不到出处的，写 `【待补：出处】`，不自拟论文标题、作者或数据。
- 只写已公开发表的成果；用户材料里有未公开的数据或成果时，在交付说明里请用户确认能否公开。
- 在交付说明里提醒用户：
  - 请同行专家做科学性审核，核查原理、数据引用和概念定义。
  - 请目标读者代表或文字编辑做可读性审核。
  - 请一位其他学科的人试读初稿，标出读不懂的词和概念。
  - 健康科普在少量目标人群中预试验后再定稿。
  - 发布时可以标注使用了大模型辅助。
  - 稿件要投征集活动或评奖时，核对通知对人工智能生成内容的要求。例如 2026 全国优质科普作品征集要求作品"非人工智能批量生成"。

## 审查清单

**所有模式：**

- [ ] 正文字数落在用户给定的篇幅内；用户没给时，落在"篇幅与读者"一节对应的区间内。
- [ ] 标题用全称和日常词，缩写只有人人都懂的那种。
- [ ] 标题没有"重磅""震惊"这类情绪词。
- [ ] 开篇段写出了新发现或核心结论；用了引子的，结论紧跟在引子之后。
- [ ] 开篇段写出了读者为什么要在乎。
- [ ] 开篇段最多一个数字，没有测量值，缩写只有人人都懂的那种。
- [ ] 成果解读的开篇段写明了研究出处。
- [ ] 正文顺序是结论在前、细节在后，不是"背景→方法→结果"。
- [ ] 成果解读有一节写局限、风险或争议。
- [ ] 每个有争议的观点都写了不同看法和各自依据。
- [ ] 辟谣与行为建议的结尾写了读者可以怎么做。
- [ ] 每个专家个人观点都写了专家的姓名和单位或身份；每项单项新研究都标明了是新研究和发表在哪里。
- [ ] 原始文献里的限定条件（实验对象、样本、"初步"）都保留在正文里。
- [ ] 标题和正文里的"突破""彻底""攻克""治愈""首次""颠覆"都有原始文献支持。
- [ ] 引用来源逐条通过了 `blocks/citation.md` 的审查清单；正文里每个统计数据和研究结果都在来源列表里有对应条目，条目有年份。
- [ ] 每个提到的伪科学说法后面都紧跟着它错在哪里和正确的说法。
- [ ] 每个保留的术语在首次出现处紧跟一句通俗解释。
- [ ] 每张图都有能独立读懂的图注，并通过了 `blocks/figure-table.md` 关于图的审查项。
- [ ] 引用的图片标明了来源。
- [ ] 文末列出了来源、作者、审核者和发布日期。
- [ ] 健康科普：写明了适宜人群或目标人群；养生保健类写明了不能替代医生的治疗或医嘱。
- [ ] 健康科普：药品、器械用通用名，没有品牌和机构推荐。
- [ ] 健康科普：每条说疗法或保健做法有效、无效的说法都附了科学依据。
- [ ] 健康科普：每条疾病风险都写了具体大小和应对办法。

审模式拿不到原始文献时，限定条件和定论式词语两条标不适用，原因写"缺原始文献"，并在问题清单里请用户提供。

**写、改写模式**（审模式看不到资料台账和交付说明，标不适用）：

- [ ] 资料台账里每条事实都有出处，正文里没有台账之外的事实。
- [ ] 用到人物肖像或个人隐私时，交付说明里写了授权情况。
- [ ] 交付说明里提醒了科学性审核、可读性审核和领域外读者试读。

## 示例

改写前：

```markdown
2026 年，某团队在《自然》发表研究，在小鼠实验中通过 CRISPR-Cas9 介导的
基因编辑技术对肝脏 PCSK9 基因进行敲除，使 LDL-C 水平降低 60%，
有望彻底治愈高胆固醇血症。
```

改写后：

```markdown
一次基因编辑，也许能让血液里的“坏胆固醇”长期降下来，不过目前只在小鼠身上做到。这项研究发表在《自然》上。

研究团队用一种“基因剪刀”关掉了小鼠肝脏里一个推高胆固醇的基因，小鼠血液中的“坏胆固醇”下降了约六成。

能否用在人身上，还要经过临床试验验证。

```
